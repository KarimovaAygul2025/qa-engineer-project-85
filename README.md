# Codebattle

**Codebattle** — соревновательная платформа для программистов от [Hexlet](https://codebattle.hexlet.io/). Участники решают задачи в реальном времени в формате «код против кода».

## Основные возможности

### Турниры и сезоны

- **4 сезона в год** — регулярные соревновательные циклы
- **Grand Slam** — финальный турнир для лучших участников
- **Swiss-система** — пары формируются по близкому уровню
- **Elo-рейтинг** — долгосрочная оценка навыков

### Форматы соревнований

- **Season ladder** — очки сезона и живая таблица лидеров
- **Swiss tournaments** — пары по текущим очкам, одна задача на раунд
- **Grades** — уровни от Rookie до Grand Slam

### Приватные турниры

- **Друзья и сообщества** — приватные комнаты, приглашения, рематчи
- **Team-building** — корпоративные турниры
- **Масштабные события** — поддержка 1000+ участников

## Поддерживаемые языки

Clojure, C++, C#, Dart, Elixir, Go, Java, JavaScript, Kotlin, PHP, Python, Ruby, Rust, Swift, TypeScript, Zig.

## Как это работает

1. **Присоединиться к сезону** — старт с обнулёнными очками
2. **Играть в Swiss-раундах** — соперники с похожим рейтингом
3. **Зарабатывать очки** — подъём в таблице и место в финале
4. **Победить в Grand Slam** — призы и мерч для чемпионов

## Сообщество

Проект открытый и развивается сообществом. Исходный код доступен на GitHub.

## Быстрый старт

- **Simple battle** — можно попробовать без регистрации
- **Live ladders** — рейтинговые матчи
- **Bots + training** — тренировка против ботов
